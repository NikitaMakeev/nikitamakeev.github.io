# PortfolioSite

Дважды нажмите `Start-Portfolio.cmd`, затем откройте http://localhost:3000.
Нужен установленный Node.js. Оставьте окно сервера открытым, пока пользуетесь сайтом.

`index.html` содержит фотографию, SVG-логотипы и переводы EN / ET / RU.
Для загрузки Tailwind CSS нужен интернет.

## Заявки

Форма отправляет данные в `server.mjs`. Успешная отправка показывается только после
записи на диск. Заявки сохраняются по одной JSON-записи на строку в
`private-data/inquiries.ndjson`. Этот файл недоступен через веб-сервер.
Уведомления на почту и календарь не подключены: новые заявки нужно смотреть в файле.

При открытии HTML двойным щелчком форма отключена с пояснением.
Контакты, копирование адреса и переход в Gmail доступны как альтернативы.

## Публикация

Для посетителей из интернета разместите `index.html` и `server.mjs` на хостинге,
который запускает Node.js, с HTTPS и постоянным диском для заявок. Одной загрузки HTML
на статический хостинг недостаточно для отправки формы.

Переменные окружения:

- `HOST` — по умолчанию `127.0.0.1`; для контейнера обычно `0.0.0.0`.
- `PORT` — по умолчанию `3000`.
- `DATA_DIR` — постоянная закрытая папка для заявок; по умолчанию `private-data` рядом с сервером.

Сервер намеренно отдаёт только HTML и принимает POST-запросы формы. Не настраивайте
публичную раздачу `private-data`. При работе за reverse proxy ограничение частоты
применяется к адресу прокси; перед публичным запуском настройте ограничение запросов
на самом прокси под ожидаемый трафик. Сделайте резервные копии папки заявок.

Чтобы подключить личный календарь после настройки, замените пустое значение
`bookingUrl` в конце `index.html` на свой HTTPS-адрес страницы бронирования.
Тогда основной CTA и отдельная кнопка в контактах станут ссылками на календарь.

Цифры производительности, аптайма и экономии времени не указаны: подтверждающих
логов или замеров пока нет. В кейсах показаны факты из резюме и упрощённые схемы.

SVG-логотипы технологий встроены из Simple Icons: https://github.com/simple-icons/simple-icons.
Они обозначают используемые технологии, а не партнёрство с владельцами брендов.
