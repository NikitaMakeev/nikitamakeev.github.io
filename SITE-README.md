# PortfolioSite

Основной файл — `index.html`. Актуальная фотография подключается из `photos/portfolioFacePhoto.png`. HTML содержит демонстрационные экраны,
SVG-логотипы и тексты EN / ET / RU. Tailwind загружается из CDN, нужен интернет.

## Контакты на GitHub Pages

- Быстрый путь: кнопка открывает чат https://t.me/daymonru.
- Подробный путь: посетитель вводит имя, почту и задачу. Кнопка «Продолжить в Telegram» открывает тот же чат с подготовленным текстом. Посетитель сам нажимает «Отправить» в Telegram. Сайт не сообщает, что сообщение уже отправлено.
- Если Telegram не открылся, под формой остаётся ссылка на подготовленное сообщение. Текст сохраняется в полях текущей страницы.

Этот сценарий работает без сервера, API-ключей, Calendly и почтовых программ.
На GitHub Pages для обновления страницы опубликуйте `index.html` и папку `photos`.
Формат ссылки: https://core.telegram.org/api/links#public-username-links.

## Необязательный серверный приём заявок

Дважды нажмите `Start-Portfolio.cmd`, затем откройте http://localhost:3000.
Нужен Node.js. Оставьте окно сервера открытым.

Страница проверяет `/api/contact-status`. Если сервер доступен, форма переключается
на прямое сохранение заявки, а кнопка называется «Обсудить проект». Успех показывается
только после записи на диск. При сбое текст остаётся в форме и доступна ссылка
для продолжения в Telegram.

Заявки записываются в `private-data/inquiries.ndjson`, по одному JSON-объекту на строку.
Этот файл не отдаётся веб-сервером. Почтовые уведомления не подключены.

Для такого приёма заявок из интернета нужен Node.js-хостинг с HTTPS и постоянным
диском. GitHub Pages серверный код не запускает.

Настройки: `HOST` (по умолчанию `127.0.0.1`), `PORT` (`3000`), `DATA_DIR`
(закрытая папка `private-data` рядом с сервером). При использовании reverse proxy
настройте на нём ограничение запросов; встроенное ограничение использует адрес
прямого соединения. Делайте резервные копии заявок.

## Содержание

Экраны — демонстрационные макеты, а не снимки клиентских продуктов. Они подписаны
и не содержат клиентских данных. В кейсах только факты из резюме: неподтверждённые
показатели скорости, экономии и конверсии не добавлены.

SVG-логотипы: https://github.com/simple-icons/simple-icons.
